# pooling-resource-manager

**KRAKEN 컨트롤러 — 자원 배분 정책·크레딧 피더·폐루프 간섭 제어**

AI 반도체 컴퓨팅 자원분해 및 자원풀링 기술 개발 (No.RS-2025-02220502)

런타임이 "어떻게 나눌지"를 실행한다면, 이 계층은 **"얼마나 나눌지"를 정하고 그 결정을 주기적으로 주입**한다.
관측 → 판단 → 조절의 폐루프를 돌려 간섭 구간에서만 제어를 개입시킨다.

---

## 구성

| 경로 | 역할 |
|---|---|
| `kraken_controller.py` | 컨트롤러 본체 |
| `scheduler.py` | 라운드 기반 크레딧 분배, 우선순위 가중치 |
| `allocator.py` | 자원 배정 |
| `overcommit.py` | 초과 배정(이중 제수) — 광고량 = 물리량 × 계수, 메모리 쿼터는 광고량으로 나눔 |
| `feeder/` | 크레딧 피더 — 주기마다 예산 × 목표비율을 각 테넌트 몫에 주입 |
| `interference/closed_loop.py` | **폐루프 간섭 제어** — 관측 리포터의 꼬리 지연을 보고 단계형으로 조이고 푼다 |
| `ratio/` | 비율 조정 |
| `booster/` | 자원 회수 가속 연동 |
| `lifecycle/` | 테넌트 생명주기 상태 기계, 원장, 구독 |
| `priority.py` | 우선순위 정책 |
| `registry.py` | 테넌트 레지스트리 |
| `schedctl.py` | 운영 CLI |
| `shm/` | 공유 메모리 자료구조 (런타임과 상태 공유) |

## 현재 구현 상태

### 동작 확인된 것

**폐루프 간섭 제어**
- 관측 리포터가 지연 민감 워크로드의 꼬리 지연을 롤링 창으로 집계 → 컨트롤러가 판단 → 비율 조절
- 히스테리시스 분리 (조이는 임계 > 푸는 임계) — 진동 없음
- **간섭이 지속될 때만** 개입 → 무개입 대비 총처리량 손실 없음
- 실측: 초과 배정 149% 구간에서 지연 민감 측 유지율 0.477 → **0.743**, 총처리량 34.9 ≈ 무개입 35.3
- 약경합 구간(100~120%)에서는 고정 제어가 오히려 손해임을 확인 → 폐루프가 개입하지 않음

**초과 배정**
- 이중 제수 방식으로 광고량과 메모리 쿼터를 분리
- 초과 배정은 총처리량을 올리지만(3테넌트 고정 +7.3%) 유지율(−6.3%p)과 꼬리(1.25→1.35배)를 대가로 함 — 공짜가 아님

**다중 테넌트 배분**
- 3테넌트 유지율 74.6~84.6%, 큰 몫이 덜 깎임
- 유휴 편승으로 총처리량이 전체 단독 대비 +6.1~13.8%

### 알려진 제약

| 항목 | 내용 |
|---|---|
| 자동 조절 테넌트 수 | 관측 판독·조절이 단일 집계 경로라 **2테넌트 구간에서만 검증**됨 |
| 대역외 조작 | 컨트롤러를 거치지 않고 직접 배선 API를 호출하면 device-plugin 캐시와 어긋남 |
| 계수 1.5 | 폐루프 상주 조건에서만 해금. 공간 겹침으로 생기는 꼬리는 시간 스로틀로 제거되지 않음 |
